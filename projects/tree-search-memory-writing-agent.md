# Tree-Search Memory Writing Agent

**Role:** Project Lead · Disruptive Talent Program

## Problem

Single-pass LLM writing provides limited control over long-range narrative quality, memory consistency, and narrator persona.

## Approach

I proposed a **Tree Search + node-scoring** framework with explicit episodic memory and narrator profiles, and built a meta-evaluation pipeline with human annotation while exploring DPO-trained scoring models as reward signals.

## Finding / Contribution

The project turns creative-writing optimization into an explicit search-and-evaluation loop, enabling controllable memory retrieval, narrator constraints, and systematic comparison against single-pass generation.
